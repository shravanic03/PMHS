Mental Health Support System

Project Overview

The Mental Health Support System (MHSS) is a web-based application designed to provide users with resources, tools, and support to improve their mental well-being. Built using React.js and styled with Tailwind CSS, this project aims to offer a user-friendly interface and a seamless experience for individuals seeking mental health support.

Features

User Authentication
Sign Up & Login: Secure user authentication using email and password.

Password Recovery: Option to reset forgotten passwords.

User Dashboard
Personalized Dashboard: Users can access their personalized dashboard with recommended resources and tools.

Mood Tracker: Track daily mood and mental health status.

Resources & Tools
Articles and Blogs: Access to a variety of mental health articles and blogs.

Self-help Tools: Interactive self-help tools like breathing exercises and meditation guides.

Community Support: Join forums and connect with others in the community.

Professional Help
Therapist Directory: A searchable directory of mental health professionals.

Booking Appointments: Users can book appointments with therapists directly through the platform.

Admin Panel
Manage Users: Admins can manage user accounts and monitor platform activity.

Content Management: Add, edit, or delete articles, blogs, and other resources.

Technologies Used

Frontend

React.js: A JavaScript library for building user interfaces.

Tailwind CSS: A utility-first CSS framework for styling.

Installation

Prerequisites

Node.js installed on your machine.

npm or yarn for package management.

Steps

Clone the repository:

git clone https://github.com/yourusername/mental-health-support-system.git

Navigate to the project directory:

cd mental-health-support-system

Install dependencies:

npm install

or

yarn install

Start the development server:

npm start

or

yarn start

Open the application in your browser:

http://localhost:3000

Deployment

Deploying to Vercel

Install the Vercel CLI:

npm install -g vercel

Deploy the project:

vercel

Follow the prompts to deploy the project.
